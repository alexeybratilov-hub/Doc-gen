# DocGen Portable — Автономный генератор документов

Переносимое автономное приложение для автоматизированного формирования комплекта документов по охране труда, стажировкам и медицинским осмотрам (по приказам Минздрава РФ № 29н и № 342н) на базе таблиц Excel и шаблонов Word (.docx).

---

## 1. Запуск «ИЗ КОРОБКИ» на Windows 10 / 11 (БЕЗ установки программ)

Вам **НЕ ТРЕБУЕТСЯ** устанавливать Node.js, Python, базы данных или Microsoft Office!

1. Распакуйте папку с приложением на рабочий компьютер или USB-флешку.
2. Просто запустите файл **`start.bat`**.
3. Приложение автоматически:
   - Если Node.js не установлен, запустит локальный защищенный сервер через **встроенный в Windows компонент PowerShell** (он есть на каждом ПК с Windows 10 и 11).
   - Если на компьютере уже есть Node.js или вы положили `node.exe` в папку `runtime\`, сервер запустится через чистый автономный скрипт `server.cjs` (без требования `node_modules` и `npm`).
   - Автоматически откроет окно вашего браузера по адресу: **`http://localhost:3000`**.
4. Для завершения работы закройте окно или запустите **`stop.bat`**.

## 2. Сценарии генерации документов

### Сценарий №1: Документы по охране труда (приём и инструктажи)
- **Вводный инструктаж** (`Вводный.docx`) — обязателен для всех оформляемых сотрудников.
- **Стажировочный лист** (`СЛ.docx`) — формируется, если для должности в справочнике указана программа стажировки. Дата начала стажировки рассчитывается автоматически как **следующий рабочий день** после даты приёма с пропуском выходных и праздников производственного календаря РФ.
- **Листы ознакомления с локальными нормативными актами (ЛНА) и инструкциями**:
  - `Лист_ИТР.docx` — лист ознакомления со всеми локальными нормативными актами предприятия и инструкциями для категории ИТР;
  - `Лист_Рабочие.docx` — лист ознакомления со всеми локальными нормативными актами предприятия и инструкциями для категории Рабочих;
  - `Лист_Офис.docx` — лист ознакомления со всеми локальными нормативными актами предприятия и инструкциями для работников офиса.
- **Направления МО и ПСО при приёме**:
  - `МО.docx` — направление на медосмотр при наличии вредных факторов;
  - `ПСО.docx` — направление на психиатрическое освидетельствование (при предварительном МО).
- Сохранение файлов с разбиением по папкам: `инструктажи\` и `Направления\`.
- Формирование обновлённого файла Excel с проставленной датой инструктажа и снятыми флагами генерации.

### Сценарий №2: Медицинские осмотры (Приказ 29н и Приказ 342н)
- Переключатель вида медосмотра: **«Периодический»** / **«Предварительный»**.
- Формирование направлений **МО** по списку контингента с учётом стажа, СНИЛС и пунктов вредности по приказу 29н.
- Формирование направлений **ПСО** только при режиме «Предварительный» (по требованию ТЗ).
- Сохранение файлов в папку `готовые_направления\`.

## 3. Ключевые возможности интерфейса

1. **Вставка массивом из Excel (Ctrl+V)**:
   - Возможность скопировать из Excel или Word сразу весь столбец (ФИО, должности и т.д.) или фрагмент таблицы и вставить в базу в один клик.
2. **Справочник должностей (Лист ДАННЫЕ)**:
   - Полный справочник из исходного процесса (ИТР, Рабочие, Офис, электробезопасность, программы инструктажей и стажировок, СОУТ).
   - Возможность добавлять и редактировать должности прямо в веб-интерфейсе.
3. **Редактор шаблонов DOCX**:
   - Встроенные стандартизированные шаблоны с тегами `{{...}}`.
   - Загрузка пользовательских файлов `.docx` с сохранением исходного фирменного оформления, логотипов и сеток таблиц.
   - Справочник тегов автоподстановки.
4. **Реквизиты организации**:
   - Настройка названия компании (по умолчанию ООО «Катания»), ОГРН, ИНН, ОКВЭД, юридического и фактического адресов, ФИО и должности руководителя для подписей.
5. **Резервное копирование и экспорт**:
   - Экспорт и импорт состояния проекта в JSON.
   - Скачивание полного дистрибутива Windows с командными файлами `start.bat` и `stop.bat` в ZIP-архиве.
   - Скачивание всех сгенерированных документов в едином ZIP-архиве.
